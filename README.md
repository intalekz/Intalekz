# Intalekz | Music, Film & Gaming

I'm Intalekz, a rap and hip-hop artist building a creative universe across music, film and gaming.

Music is where it started. Now the work extends into cinematic storytelling, original characters and **Lekz Jump**, a game in development. Different formats, one creative vision.

**[Official website](https://www.intalekz.com/) · [YouTube](https://www.youtube.com/@intalekz) · [SoundCloud](https://soundcloud.com/intalekz) · [X](https://x.com/intalekz)**

## Gaming | Lekz Jump

**Lekz Jump is in development.** It brings the characters into a portal-crossing adventure through fractured worlds.

Current work includes character and environment reference artwork for future 3D models and game development. The website introduces the cast and the world; it is not a playable game release.

[Explore Lekz Jump](https://www.intalekz.com/lekz-jump)
